# Formula 1 Race Intelligence Dashboard & Analysis Report

## Overview
An interactive Data Analytics capstone project analyzing Formula 1 race dynamics, tyre degradation strategies, driver/constructor championship trends, and DNF metrics across 17 seasons and 29 circuits. Built using Tableau and Python (Flask).

## Live Interactive Dashboard
- **Tableau Public URL**: [Formula 1 Race Intelligence Dashboard](https://public.tableau.com/app/profile/bhuvan.mishra/viz/Bhuvan_F1_Project/F1RaceIntelligenceProvidedDataset)

## Project Deliverables
- `Bhuvan_F1_Project.twbx`: Tableau Packaged Workbook containing the 9 unique visualizations, interactive dashboard, and 9-scene Story.
- `F1 Racing Project Dataset.xlsx`: Multi-sheet relational F1 dataset (circuits, race_results, championship_standings, lap_intelligence, qualifying_results).
- `F1 Project Documentation.docx`: Detailed project report covering data preprocessing, architecture, visual analytics, and insights.
- `F1 Project pptx.pptx`: Comprehensive project demonstration slide deck.

## Project Structure & Key Epics Covered
- **Epic 1 & 2**: Data ingestion, relationships (`race_id`, `circuit_id`), DNF calculations, and data extract configuration.
- **Epic 3 & 4**: 9 unique visual charts and responsive dark-themed dashboard.
- **Epic 5**: 9-scene interactive Story covering driver leaderboards, tyre strategy, reliability, and team outcomes.
- **Epic 7**: Tableau Public deployment and Flask web integration.
